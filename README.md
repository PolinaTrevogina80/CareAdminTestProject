# CareAdminTestProject

Автоматизированные End-to-End тесты для системы администрирования медицинских инцидентов (Care Administration) с использованием **C#** и **Playwright**.

## 📌 Описание проекта
Данный фреймворк разработан для автоматизации сложных бизнес-процессов ведения инцидентов, включая ролевые модели, цепочки последовательных подписей (Director of Nursing, Medical Director, Administrator) и валидацию состояний Angular-форм.

## 🛠️ Стек технологий
* **Язык**: C# (.NET)
* **Инструмент автоматизации**: Playwright
* **Тестовый фреймворк**: NUnit
* **Управление конфигурацией**: JSON-ориентированные среды

## 🚀 Архитектурный Roadmap (Планы по рефакторингу)
Проект изначально создавался как MVP в условиях жестких дедлайнов. Сформирован следующий бэклог архитектурных улучшений:

1. **Декомпозиция слоя Steps (Fluent Interface)**: Разбиение монолитного класса `Steps` на изолированные подклассы по зонам ответственности (`IncidentCreationSteps`, `IncidentSummarySteps`, `AttachmentSteps`) с поддержкой цепочечного вызова методов.
2. **API-driven Auth**: Перевод авторизации в тестах на API-уровень (получение токена через POST-запрос в `[SetUp]`) для ускорения прогона тестовых наборов.
3. **Динамическое обеспечение данными (Database Data Provisioning)**: Интеграция с тестовой БД/API для динамического поиска активных резидентов по сложным бизнес-критериям прямо во время инициализации теста (вместо статического хардкода ID).
4. **Конфигурация сред**: Полный перенос настроек стендов и ролевых доступов в `testEnvironments.json`.
